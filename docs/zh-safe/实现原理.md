# 离线原理图 PDF 差异扫描实现原理

## 为什么不能只做整页像素差

原理图包含细线、密集文字、重复符号和页框。导出偏移、扫描噪声、页面旋转和文字对象拆分都会放大整页像素差。系统因此分别提取页面身份、文字、OCR、视觉几何和局部语义，再统一融合。

## PDF 输入

`pypdf` 用于检查文件结构、页数和加密状态；`pdfplumber` 用于文字与字符坐标；`pypdfium2` 用于本地页面渲染。扫描页在需要时调用本机 Tesseract。

所有持久坐标使用 PDF 点，而不是某个 DPI 下的像素坐标。

## 页面配对

每页生成两类指纹：

- 规范化文字词元。
- 缩小后的墨迹缩略图。

页面相似度同时考虑文字、视觉内容和页面纵横比。动态规划负责建立保序配对，允许中间插入或删除页面。

## 文档预检

页面配对后先计算可靠匹配覆盖率、相似度中位数、强匹配比例和复核比例。证据不足时停止比对，避免将不同项目误报成大量页面新增和删除。

## 配准

先估计平移，再根据配置尝试受限仿射变换。旋转、缩放、错切和位移均有限制，候选变换只有在实际降低差异时才会接受。

## 文字差异

词级比较负责值替换和网标变化，字符级比较补充被 PDF 拆开的文字。差异片段保留旧页和新页坐标，并排除明显的序列化、引脚和重叠碎片。

## 视觉差异

像素差先经过阈值和细线保护，再按连通区域分组。视觉区域用于发现连线、符号、注释框和其他非文字变化。

## 语义关联

局部文字上下文用于恢复：

- 位号。
- 元件值。
- 网络标号。
- 电源轨。
- 引脚和内部标签。

融合器根据位号、共享网络、空间距离和文字重叠决定合并或拆分审阅项。

## 移动块

局部电路从一处搬到另一处时，普通页面差异会同时产生删除和新增。移动块识别会比较两侧位号身份集合和相对布局，确认整体搬运后输出一条移动记录，并保留源页和目标页定位。

## 报告

报告器为变更页生成预览，为审阅项生成高分辨率局部特写。线稿优先使用体积较小的无损 WebP，扫描照片可回退到高质量 JPEG。

最终 HTML 内嵌 CSS、JavaScript、差异数据和高清图像，可以离线打开并单独分发。浏览器支持滚轮缩放、拖动平移和双击复位。

## 测试策略

- 几何与页面配对单元测试。
- 合成矢量 PDF 和扫描 PDF 测试。
- 页面身份预检和不同项目拦截。
- 同页与跨页移动块识别。
- Web 任务状态、独立报告和下载流程。

测试数据不得包含真实客户原理图、位号、网络清单或变更表。
