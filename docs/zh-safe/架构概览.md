# 离线原理图 PDF 差异扫描架构

## 目标

系统接收两版原理图 PDF，输出可定位、可复核的差异结果。运行期间不依赖网络，不把 PDF 上传到云服务。

核心约束：

- 支持矢量页和扫描页。
- 允许页面尺寸、旋转、插入、删除和小范围偏移。
- 同时保留文字、图像和语义证据。
- 报告可以独立分发。
- 错误、弱匹配和不确定结果必须显式提示。

## 分层

| 层 | 职责 |
| --- | --- |
| 接口层 | CLI、本机 Web 上传、任务状态和结果下载 |
| 输入层 | PDF 安全检查、文字提取、栅格渲染和本地 OCR |
| 文档层 | 页面指纹、页面配对、文档身份预检 |
| 差异层 | 页面配准、文字差异、视觉差异 |
| 语义层 | 位号、元件值、网络、注释和移动块关联 |
| 输出层 | JSON、独立 HTML、证据图、运行清单和日志 |

## 处理流程

1. 检查 PDF 文件头、大小、加密状态和页数。
2. 建立页面文字指纹与墨迹缩略图，计算页面相似度。
3. 使用保序动态规划配对页面。
4. 根据覆盖率与相似度判断两份 PDF 是否属于同一套原理图。
5. 对每个配对页提取文字并渲染灰度图。
6. 估计保守平移或仿射变换。
7. 分别生成文字差异和视觉差异区域。
8. 将证据转换为 PDF 点坐标并关联位号、元件值和网络。
9. 识别整体移动的局部电路，抑制源位置的删除噪声和目标位置的新增噪声。
10. 生成独立 HTML、JSON 和带框图。

## 文档身份预检

文档预检发生在逐页差异和报告生成之前。

- 没有可靠匹配页：拒绝。
- 可靠配对覆盖率不足：拒绝。
- 匹配相似度中位数过低：拒绝。
- 只存在弱匹配：继续处理，但报告显示人工复核警告。
- 页面新增或删除本身不会导致拒绝，判断依据是其余页面能否形成稳定对应关系。

## 证据模型

每个审阅项保留：

- 旧页和新页页码。
- 旧页和新页 PDF 点坐标。
- 文字、OCR、视觉或移动块来源。
- 前后文字或值。
- 位号、网络和置信度。
- 底层证据 ID 和判断原因。

## 安全边界

- 比对进程不允许主动建立网络连接。
- 报告 CSP 禁止外部连接。
- PDF JavaScript、嵌入文件和外部动作不执行。
- Tesseract 通过本地子进程和标准输入运行。
- 源 PDF 不直接嵌入最终报告，页面和证据由工具重新渲染。

## 非目标

工具不替代电气设计评审，不重建完整 EDA 网表，也不保证仅凭截图就能判断所有电气正确性。
